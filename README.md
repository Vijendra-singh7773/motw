# MOTW Coffee & Pastries — Oakville Demo

Premium animated static website concept for MOTW Coffee & Pastries, 335 Kerr Street, Oakville, Ontario.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Notes
- Built with HTML, CSS and vanilla JavaScript.
- GSAP + ScrollTrigger loaded via CDN.
- Image backgrounds use remote Unsplash URLs for the demo; replace with client-approved MOTW photography before production.
- Menu details were based on publicly available MOTW menu information and should be reconfirmed before launch.
